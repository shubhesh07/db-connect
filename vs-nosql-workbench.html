DB Connect vs NoSQL Workbench

Both are free. NoSQL Workbench is AWS's tool for designing DynamoDB data models. DB Connect is built for the daily work that follows: querying, editing, cost-checking and administering live tables.

Where NoSQL Workbench is better

📐

Data modelling first

Define tables, keys and GSIs, add sample data and visualise how items lay out for each access pattern — before you write any code. DB Connect has no modeller.

☁

Official AWS tool

Free from AWS and built only for DynamoDB, so it follows the service closely.

💻

Code generation

The operation builder can generate SDK code for the request you built, ready to paste into your application.

🐧

DynamoDB Local and Linux

It can run DynamoDB local for you and it runs on Linux. DB Connect connects to DynamoDB Local but you start it yourself, and it is macOS and Windows only.

Where DB Connect is better

💰

See what each query costs

Every Scan, Query and PartiQL statement reports items returned, items scanned, scan efficiency and RCUs consumed, and warns when DynamoDB stopped at its 1 MB page.

🔢

Typed items, exact numbers

Items are edited with their DynamoDB types and numbers keep full precision — no silent rounding of large IDs.

🔍

GSI-aware builder and PartiQL

Query a table or any GSI without writing expressions, or write PartiQL with autocomplete and page through results with Load more.

🧹

Guarded bulk work

Batch delete with a dry run first, and JSON import/export behind a cost gate. Production-tagged connections ask before destructive statements.

⚙

Table admin

Create and delete tables, change capacity, manage GSIs, TTL, point-in-time recovery, backups and streams.

🔑

AWS auth and your other databases

Access keys, SSO profiles, the instance/task role and default credential chain, and assume-role with MFA. Plus MySQL/MariaDB, PostgreSQL, Redshift, Redis, MongoDB and Elasticsearch/OpenSearch in the same app.

Who should pick which

Pick NoSQL Workbench if…

you are designing a new table, want to share a data model with your team, want generated SDK code, or work on Linux.

Pick DB Connect if…

you operate live tables every day — querying, editing, checking cost, running admin tasks across accounts with assume-role and MFA — or you also work with SQL databases. A natural pairing: model in NoSQL Workbench, operate in DB Connect.

Frequently asked

Is there a free alternative to NoSQL Workbench for DynamoDB?

Yes. DB Connect is a free DynamoDB GUI for macOS and Windows with a GSI-aware query builder, PartiQL with paging, typed item editing, per-query cost and table admin. It is built for operating tables rather than modelling them.

Is there a DynamoDB GUI that shows RCU cost per query?

DB Connect shows items returned, items scanned, scan efficiency and RCUs consumed for every Scan, Query and PartiQL statement, and warns when DynamoDB stopped at its 1 MB page.

Does DB Connect work with DynamoDB Local?

Yes. Set a custom endpoint URL in the connection form and point it at your DynamoDB Local instance.

Can DB Connect run PartiQL queries on DynamoDB?

Yes. There is a PartiQL editor with table and attribute autocomplete, and Load more continues through results page by page.

Does DB Connect support AWS SSO and assume-role with MFA?

Yes. Access keys, SSO profiles, the instance/task role and default credential chain, and assume-role with MFA.

Can DB Connect design DynamoDB data models like NoSQL Workbench?

No. DB Connect has no data modeller. Use NoSQL Workbench to design tables and access patterns, and DB Connect to query and administer the live tables.
